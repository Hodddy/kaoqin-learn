5.3　用 JS 调接口（fetch），把结果画成表格

本课目标：理解前端怎么"问后端要数据"，再把数据显示出来。这是前后端的连接点。

① fetch = 前端的"发请求"

JS 用 fetch 向后端接口发请求，等后端回数据。这就是模块 1 "一问一答"在前端的写法。

const r = await fetch('/api/clients');  # 发 GET 请求
const list = await r.json();            # 把回来的 JSON 取出来
# 然后用 list 去填下拉框
🔑 fetch(地址) 发请求；.json() 取回数据；再用数据更新页面。

② 上传文件用 FormData

点"开始核对"时，JS 把两个文件 + 月份打包进 FormData，fetch(..., {method:'POST', body: 表单}) 发给后端。

③ 把结果"画"出来

后端回的 JSON 里有每个人的结果。JS 用循环，一行行生成 <tr> 塞进表格，OK 绿、异常红。
这就是你点完核对，结果表"自己长出来"的原理。

④ 小结

fetch 发请求.json() 取数据FormData 传文件循环生成表格行
🧠 记忆点：fetch 要数据 → 拿到 JSON → 循环画进表格
