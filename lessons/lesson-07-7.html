7.7　与 IT 部门交涉清单：你要什么、给什么、怎么说

本课目标：拿着这页，就能跟公司 IT 把部署谈下来。

① 先一句话讲清你的系统（给 IT 的"自我介绍"）

"一个 Python(FastAPI) 写的内部 Web 系统，HR 上传两个 Excel 在线核对考勤、下载结果。监听 8000 端口，建议只放内网，前面用 Nginx 反代 + HTTPS。我可以提供 Docker 镜像，你们 run 起来即可。"

② 你要向 IT 申请的（清单）

项说法
一台服务器"要一台 Linux 服务器（或一个能跑 Docker 的环境），内网即可"
端口放行"放行 8000（或交给 Nginx 走 80/443）"
域名"给个内网域名，如 kaoqin.公司.com，配好 DNS 指向这台机器"
HTTPS 证书"申请一张证书（内网证书或公司统一证书）"
访问范围"限公司办公网段/HR 组白名单；外部走 VPN"
账号/数据"是否接公司统一登录(SSO)；数据存哪、要不要备份"

③ 你需要交付给 IT 的（你的活）

  • Docker 镜像 或 部署包 + 一份部署文档（我们项目已有 docs/web-deployment.md 可直接给）。
  • 需要的环境说明：Python 版本、端口、依赖、数据目录。
  • 启动方式（systemd 配置 / docker run 命令）。
  • 上线前要补的安全项：鉴权、HTTPS、限制上传（见 7.5）。

④ 对接时容易被问的，提前想好

  • "谁能访问？" → 内网 + HR 白名单（+ VPN）。
  • "数据安全吗？" → 临时文件处理、可加登录、HTTPS 加密。
  • "挂了怎么办？" → systemd 自动重启、有日志、可备份。
  • "占多少资源？" → 轻量，一台普通服务器足够。

★ 补充：SSO（公司统一登录）是什么

SSO = 单点登录：公司里登录一次、所有系统通用，不用每个系统单独注册账号、记一堆密码。你登了公司统一账号（钉钉/企业微信/微软365/AD域账号），打开邮箱、OA、考勤系统都自动认得你。

对你项目的意义：如果接了公司 SSO，就不用自己做登录，直接复用公司账号体系——更安全、员工也方便。开会时一句话："能否接公司统一登录(SSO)？"
底层技术（知道名字即可）：OAuth/OIDC、SAML、LDAP/AD。

📒 配套速查卡

开会前扫一眼 → 跟 IT 对话·名词速查（端口/服务器/内网域名/网段/VPN/SSO 等全有，配人话+例子）。

⑤ 小结

先讲清系统是什么要：服务器/端口/域名/证书/白名单给：镜像+部署文档提前备好安全问答
🧠 记忆点：你提供"打包好的程序+文档"，向 IT 要"服务器+网络+证书"
