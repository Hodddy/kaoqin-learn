2.7　看懂报错 与 调试入门

本课目标：报错不再慌——会读 Traceback、会用 print 找问题。

① 报错（Traceback）怎么读

报错是一长串，从下往上看，最后一行最关键：它告诉你"什么错 + 哪句话"。

Traceback (most recent call last):
  File "hello.py", line 3, in <module>   # 出错在第 3 行
NameError: name 'nam' is not defined      # 错误类型 + 原因
🔑 报错先看最后一行（什么错），再看上面的文件:行号（哪出的）。

② 常见几种错（认脸）

错误意思
NameError用了一个没定义的名字（多半打错字）
TypeError类型不对（拿文字去做减法之类）
IndexError列表取第 N 个，但根本没那么多（越界）
ModuleNotFoundErrorimport 的工具没装 / 名字错

③ 最朴素也最好用：print 大法

不知道程序跑到哪、变量是啥？在可疑的地方加 print(变量)，跑一遍看它打印什么，立刻定位问题。我们排 GitHub 那个 bug，就是一步步打印、缩小范围找到的。

④ 小结

报错看最后一行文件:行号 定位print 大法找问题
🧠 记忆点：别怕红字——倒着看，最后一行说人话
