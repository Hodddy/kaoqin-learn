1.1　程序、文件、"运行"到底是什么

本课目标：分清"文件 / 程序 / 运行"三个词，并真正看懂"运行"是怎么回事。

①三个词，先分清

📄
文件 File
电脑里存的一份东西，有名字、内容、类型（看后缀）。平时静静躺着不动。
📜
程序 Program
一种特殊文件，里面是一步步的指令，用来指挥电脑干活（如 .py / .exe）。
▶️
运行 Run
让电脑真的照指令去做，产生结果（弹窗、算数、生成文件…）。
🔑 一句话：文件是"躺着的东西"，运行是"让它动起来干活"。

②生活比喻：菜谱 🍳

📜
菜谱
= 代码文件 .py
→
👨‍🍳
厨师
= python
→
🍜
上菜
= 运行结果

菜谱放抽屉里不会自动变出菜（文件躺着）；交给厨师照做，才有菜上桌（运行→结果）。
所以 .py 自己不动，要交给 python 去跑——这就是我们总写 uv run python xxx.py 的原因（="让厨师照这张菜谱做"）。

③文件类型：看后缀认身份

后缀是什么
.xlsxExcel 表格（数据）
.html网页
.pyPython 代码（程序 / 菜谱）
.exe能直接双击运行的程序（成品）

④"躺着" vs "运行"（你刚亲眼看过的演示）

📄 hello.py（文件躺着的样子）
print("你好，我是一个程序，我被运行起来了！")
print("1 + 1 =", 1 + 1)
▶
▶️ 运行后的结果
你好，我是一个程序，我被运行起来了！
1 + 1 = 2

左边是文件本身（一份文字，不会动）；交给 python 运行后，右边才"动起来"产出结果。

⑤在我们项目里长什么样

run_gui.py · web/server.py程序（菜谱 .py）
releases\考勤核对系统_v2.0.exe成品程序（双击即跑）
web\static\index.html网页
2026年5月公司数据.xlsx数据（不是程序）

你见过的"运行"：双击 .exe → 弹出核对窗口；我敲 uv run python -m uvicorn … → 起了 Web 服务。

⑥动手 & 小结

✍️ 动手 2 分钟（只用鼠标，不敲命令）

  1. 打开你存放本项目的文件夹，进到里面的 learn 子目录，看到你的第一个程序文件 hello.py——它现在正"躺着"。
  2. 回到项目文件夹根目录，扫一眼里面的文件，心里给每个分类：程序(.py/.exe) / 网页(.html) / 数据(.xlsx)。
  3. 想亲手运行它？怎么用命令运行是 1.3 / 2.1 课的内容，到时手把手教，现在你已看过效果了。

✅ 本课小结

文件 = 躺着的东西（看后缀知类型） 程序 = 写着指令的特殊文件 运行 = 照指令做、出结果 .py 靠 python 跑；.exe 是成品
🧠 记忆点：菜谱(.py) → 厨师(python) → 上菜(运行结果)
