7.5　安全与鉴权：登录、token、最小权限

本课目标：让系统"只让该用的人用"，并守住几条安全底线。

① 鉴权 = 先证明"你是谁、能不能用"

现在 Web 版没有登录，谁打开都能用、能上传——内网小范围还行，对外或正式用必须加。两个词：
· 认证(谁)：登录，证明你是张三。
· 授权(能干啥)：张三能不能看别人的、能不能管理。

② token：登录后的"通行证"

登录成功后，服务器发一个 token（一串令牌）。之后每次请求带上它，服务器一看就知道"是已登录的张三"。还记得我们调 GitHub 时请求头里的 Authorization: Bearer … 吗？那就是 token。

③ 几条安全底线（跟 IT 谈也会被问）

  • 最小权限：给的权限够用就行，别什么都开（我们给 GitHub token 选 scope 时就用了这原则）。
  • 密钥别进代码/聊天：密码、token 用环境变量或密钥管理，别硬写进代码、别明文发（你那个 PAT 用完该吊销）。
  • 全程 HTTPS：别让密码明文在网上跑。
  • 限制上传：限文件类型/大小，防恶意文件。

④ 小结

认证(谁)+授权(能干啥)token=通行证最小权限密钥别明文
🧠 记忆点：先登录拿 token，权限给最小，密钥不外露
