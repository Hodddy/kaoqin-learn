2.1　Python 是什么 + 用 uv 安装运行

本课目标：搞懂"语言 / 解释器 / uv 工具"三者关系，并会用一条命令运行代码。

① 一句话先懂

  • Python = 一种编程语言（写"菜谱"用的语言，人能读、机器能执行）。
  • 解释器（也叫 python） = 照菜谱做菜的"厨师"——把你的 .py 翻译成机器动作。
  • uv = 一个"管家工具"：帮你装 Python、管依赖、统一运行，省得手忙脚乱。
🔑 你写语言(Python) → 管家(uv)调厨师(python) → 把菜谱跑出来。

② 为什么用 uv（而不是直接 python）

  • 统一、干净：不污染系统、不同项目互不打架。
  • 一条命令搞定运行 + 依赖。我们整个项目都靠它。
  • （这也是本项目的硬规矩：Python 一律用 uv 跑。）

③ 在我们项目里长什么样

我们一直敲的就是它：
uv sync（第一次 / 换电脑：按 uv.lock 把依赖一次装齐）
uv run python run_gui.py（跑桌面版）
uv run python run_web.py（起 Web 服务）
本项目是「标准 uv 项目」：依赖写在 pyproject.toml、版本锁在 uv.lock，uv sync 一键装到项目自带的 .venv 文件夹，之后 uv run 会自动用它（不用再加 --no-project）。

④ 动手 & 小结

✍️ 动手

  • 打开终端，进到项目文件夹（用 cd 切到你存放本项目的目录，每台电脑可能不一样）。
  • 运行你第一课那个程序：uv run python learn\hello.py
  • 看到 你好… 和 1 + 1 = 2 = 成功！你刚亲手"调厨师做了菜"。

✅ 小结

Python=语言python=解释器(厨师)uv=管家工具uv run python 文件
