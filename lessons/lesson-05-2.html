5.2　表单、文件选择、按钮

本课目标：认识用户"输入/选择/点击"用到的 HTML 元素。

① 几个最常用的标签

标签是什么
<button>按钮
<input type="file">选文件
<input type="text">文本输入框
<select>下拉选择
<table>表格

标签都是"成对"的：<button>开始</button>，中间是显示的内容。

② 在我们项目里

界面上你看到的：
"选择文件"按钮 = <input type="file">（藏起来）+ 一个 <button> 触发它；
"客户"下拉 = <select>；月份胶囊 = 一堆带 <input type="checkbox"> 的标签；
结果区 = 一个 <table>。

③ 小结

button 按钮input file 选文件select 下拉table 表格
🧠 记忆点：界面上每个能点能填的东西，背后都是一个 HTML 标签
