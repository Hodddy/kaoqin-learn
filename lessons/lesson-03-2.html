3.2　数据模型 dataclass：把一行考勤变成"对象"

本课目标：理解为什么不直接用一堆变量，而是打包成"对象"。

① 问题：一个人有一堆信息

一个员工：姓名、应出勤、实际出勤、加班、请假、漏签…… 如果用一堆零散变量，传来传去很乱。把它们打包成一个"对象"，就清爽了。

② dataclass = 自定义的"数据盒子模板"

from dataclasses import dataclass
@dataclass
class CompanyRecord:
    name: str            # 姓名
    ying_qin: float = 0  # 应出勤
    actual:   float = 0  # 实际出勤

之后 comp = CompanyRecord(name="张三")，就能 comp.name、comp.actual 一个点取一个值。

🔑 dataclass = 你自己设计的一种"数据格式"，把相关信息装一起。

③ 在我们项目里

core/models.py 里定义了一堆：
CompanyRecord（公司侧一个人）、ClientMonthlyRecord（客户侧一个人）、ReconcileResult（核对结果）。
解析时把每个人填成一个对象，核对时直接比两个对象的字段——清楚又不易错。

④ 小结

对象=打包好的一组信息@dataclass 定义模板用 对象.字段 取值
🧠 记忆点：一个人 = 一个对象，点一下取一个属性
