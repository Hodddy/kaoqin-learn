6.2　SQL 与 SQLite 入门

本课目标：认识"表"的概念和操作数据的四句话。

① 数据库长什么样：就是"表"

关系型数据库里数据装在表里，跟 Excel 很像：有列（字段）、有行（记录）。比如一张"核对记录"表：

id姓名月份是否通过
1张三2026-05是
2李四2026-05否

② SQL = 跟数据库说话的语言（四句话）

SQL意思对应 HTTP
INSERT增（存一条）≈ POST
SELECT查（翻出来）≈ GET
UPDATE改≈ PUT
DELETE删≈ DELETE
🔑 增删改查 = INSERT / SELECT / UPDATE / DELETE，数据库就这四件大事。

③ SQLite：最轻量的数据库

SQLite 就是"一个文件就是一个数据库"，不用单独装服务，Python 自带 sqlite3 直接能用——非常适合给本项目加"历史记录"练手。大公司常用 MySQL/PostgreSQL，但概念一样。

④ 小结

数据装在表里(像Excel)增删改查=INSERT/SELECT/UPDATE/DELETESQLite=一个文件即库
🧠 记忆点：表像 Excel，SQL 就增删改查四句话
