2.4　条件判断 与 循环

本课目标：让程序"会拐弯"（满足才做）和"会重复"（一批一批做）。

① 条件 if / else：满足才做

if 出勤 < 应出勤:
    print("有缺勤")
else:
    print("全勤")

"如果…就…，否则…"。注意冒号 : 和下面那行的缩进（空格），Python 靠缩进表示"属于这一块"。

② 循环 for：一个一个处理

for m in ["2026-05", "2026-06"]:
    print("正在处理", m)
# 会依次打印两行
🔑 if = 拐弯（做不做），for = 重复（对一堆东西逐个做）。

③ 在我们项目里

for cname, cs in client_monthly.items(): —— 逐个员工核对（循环）。
  if not comp: —— 如果公司数据里没这个人，就标异常（条件）。
整个"核对每个人"就是"循环 + 条件"的组合。

④ 小结

if/else 条件for 循环冒号+缩进表示"这一块"
🧠 记忆点：if 决定做不做，for 把一堆东西挨个做一遍
