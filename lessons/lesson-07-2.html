7.2　让服务常驻：systemd / 进程守护

本课目标：理解"为什么不能靠黑窗口"，怎么让服务稳稳一直跑。

① 问题：黑窗口一关就停

本机版关掉黑窗口、注销、重启，服务就没了。服务器上不能这样——要它开机自启、崩溃自动重启、后台常驻。

② 解决：进程守护（Linux 用 systemd）

systemd 是 Linux 自带的"服务管家"。你写一个小配置文件告诉它"怎么启动我的程序"，它就负责常驻、看护、自启。

# /etc/systemd/system/kaoqin.service
[Service]
ExecStart=uvicorn web.server:app --host 0.0.0.0 --port 8000
Restart=always        # 崩了自动拉起
[Install]
WantedBy=multi-user.target  # 开机自启
🔑 systemd = 服务器版的"自动启动 + 永不下班 + 摔倒自己爬起来"。

③ 常用命令（了解即可）

  • systemctl start kaoqin 启动、stop 停止、restart 重启
  • systemctl enable kaoqin 开机自启
  • systemctl status kaoqin 看是否在跑

（Windows 服务器可用"任务计划/NSSM"达到类似效果，但生产环境绝大多数是 Linux。）

④ 小结

别靠黑窗口systemd 守护进程自启+自动重启+常驻
🧠 记忆点：交给 systemd，它替你 7×24 看着服务
