6.3　实战：给项目加"保存历史核对结果"

本课目标：把数据库用到我们项目上，实现界面预留的"历史记录"。

① 思路（三步）

  • 建表：建一张 history 表，存：时间、客户、月份、总人数、OK 数、异常数、结果文件路径。
  • 每次核对完写一条：在 run_reconcile 结束后 INSERT 一行。
  • 历史页查出来：加个 GET /api/history 接口，SELECT 所有记录，前端"历史记录"页显示。

② 代码骨架（SQLite）

import sqlite3
db = sqlite3.connect("history.db")
db.execute("CREATE TABLE IF NOT EXISTS history(时间,客户,月份,OK,异常)")
db.execute("INSERT INTO history VALUES(?,?,?,?,?)", (now,客户,月份,36,3))
db.commit()
rows = db.execute("SELECT * FROM history").fetchall()  # 查出来

③ 跟我们项目怎么接

界面左边那个灰色的"🕘 历史记录"占位，就是给这个功能预留的。
做完之后：每次核对自动留痕，点"历史记录"能看到过去所有批次、还能重新下载——项目就从"算完即走"升级成"有记忆"了。

④ 小结

建表→每次INSERT→历史页SELECTSQLite 一个文件让项目"有记忆"
🧠 记忆点：建表 → 存一条 → 查出来，历史记录就成了
