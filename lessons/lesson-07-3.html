7.3　反向代理 Nginx + HTTPS 证书

本课目标：理解为什么要在程序前面再加一层 Nginx，以及 HTTPS 是什么。

① 反向代理 = 程序前面的"前台接待"

不让用户直接访问你的 uvicorn，而是前面摆一个 Nginx 当门面：用户先到 Nginx，Nginx 再转给后面的程序。

用户
→
🛡️

前台/反代
→
⚙️
uvicorn
你的程序

② Nginx 帮你干什么

  • HTTPS 加密：在 Nginx 上装证书，用户到 Nginx 这段是加密的（后面讲）。
  • 用标准端口 443，用户不用记 :8000。
  • 挡一挡攻击、限流、配多个服务。

③ HTTPS 是什么

HTTP 是明文（传输能被看到）；HTTPS = HTTP + 加密，靠一张"证书"建立加密通道，浏览器显示一把🔒小锁。证书可找 IT 申请，或用免费的 Let's Encrypt（Caddy 还能自动办证）。
大公司基本强制 HTTPS，这点你跟 IT 谈时会被要求。

④ 小结

Nginx=前台/反向代理HTTPS=加密的HTTP证书建加密通道🔒
🧠 记忆点：Nginx 当门面 + 上证书 = 安全、专业的对外入口
