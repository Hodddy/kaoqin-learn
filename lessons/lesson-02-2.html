2.2　变量、数字、字符串、布尔

本课目标：会用"变量"存东西，认识最基本的几种数据。

① 变量 = 贴了名字的盒子

变量就是给一份数据起个名字，方便反复用。等号 = 是"放进盒子"，不是数学的"相等"。

name = "张三"      # 盒子 name 里放了文字 张三
age  = 25         # 盒子 age 里放了数字 25
print(name, age)  # 显示：张三 25
🔑 名字 = 值 ：把右边的东西，装进左边这个名字的盒子。

② 四种最基本的数据

类型是什么例子
整数 int不带小数的数25、0
小数 float带小数点的数0.3、18.5
字符串 str文字（必须用引号包起来）"张三"、"2026-05"
布尔 bool真 / 假（只有两个值）True、False

③ 在我们项目里

TOL = 0.3 —— 一个小数变量，表示"容差 0.3 天"。
name = clean_name(row[0]) —— 字符串变量，存清洗后的姓名。
passed = True（或 False）—— 布尔变量，表示这个人核对"过没过"。

④ 动手 & 小结

✍️ 动手

  • 打开 learn\hello.py，在最上面加一行：my_name = "你的名字"
  • 再加一行：print("我是", my_name)，保存后重新运行，看它显示出来。

✅ 小结

变量=贴名字的盒子= 是"放进去"数字/字符串(带引号)/布尔(真假)
🧠 记忆点：变量是盒子，文字要加引号，真假就 True/False
