1.3　IP · 端口 · 域名 · DNS：机器怎么互相找到

本课目标：搞懂 127.0.0.1:8000 和 github.com 背后这 4 个词。

① 四个词，一个比喻全串起来 🏢

📍 IP 地址
如 192.168.1.20、127.0.0.1
每台机器在网络里的"门牌号"。127.0.0.1 特指"我自己这台"。
🚪 端口 Port
如 8000、443、80
同一台机器上"哪个服务/几号房间"。一台机器能开很多服务，用端口区分。
🏷️ 域名 Domain
如 github.com
给 IP 起的"好记名字"，因为数字 IP 难记。
📒 DNS
域名 → IP 的查号台
你说域名，它帮你查出对应的 IP，再去连。
🏢 比喻：IP=楼栋门牌，端口=几号房间，域名=店名，DNS=把"店名"翻成"地址"的查号台/导航。

② 拆开 127.0.0.1:8000

127.0.0.1 : 8000
门牌号（哪台机器）
= 我自己这台几号房间（哪个服务）
= 8000 号窗口

所以这串就是："去我自己这台电脑的8000 号窗口"。换成局域网就是 192.168.1.20:8000（别人的机器门牌 + 同样 8000 房间）。

地址含义
127.0.0.1 / localhost本机（我自己）
192.168.x.x局域网里的某台机器（公司内网常见）
常见端口 80/443网站默认端口（80=http，443=https），所以平时上网不用写端口

③ DNS 怎么工作（你打开 github.com 时）

⌨️
你输 github.com
人记得住的名字
问 DNS →
📒
DNS 查号台
名字→IP
查到 IP →
🖥️
连到那台机器
真正按 IP 去访问

机器之间其实只认 IP（数字门牌）；域名是给人看的。每次访问域名，电脑先偷偷问 DNS"它的 IP 是多少"，再去连。

④ 在我们项目里 & 将来部署

· 本机版：127.0.0.1:8000（自己的门牌 + 8000 房间）
· 局域网共享：同事用 192.168.1.20:8000（你这台的门牌）
· 大公司正式部署：会给一个域名，比如 kaoqin.公司.com，背后 DNS 指向服务器 IP，端口走 443（HTTPS）。
—— 模块 7 跟 IT 谈的，很多就是"给我一个域名、开放哪个端口、配 DNS"。

⑤ 动手 & 小结

✍️ 动手 2 分钟（打开"命令提示符 / 终端"，敲两条看看）

  1. ping github.com —— 会显示出 github 的一个 IP 地址（域名→IP 你亲眼看到了）。
  2. ipconfig（Win）—— 找 IPv4 地址，那就是你这台电脑在局域网里的门牌号（局域网共享时同事就用它）。
  3. （不会开终端没关系，2.1 课会手把手教；现在看个印象即可。）

✅ 小结

IP = 机器门牌号 端口 = 几号房间/哪个服务 域名 = 好记的店名 DNS = 店名翻成地址
🧠 记忆点：域名(店名) → DNS(查号台) → IP(门牌) → 端口(房间)
