① 这是什么系统

一个把「公司考勤」与「客户考勤」逐月对账的工具：上传两份 Excel → 自动核对应出勤/出勤/加班/请假、算迟到漏签罚款 → 输出处理后的结果表（异常行高亮）。有两种形态：桌面 EXE 版（单机）和 Web 版（浏览器，FastAPI）。核对逻辑两版共用。

③ 项目结构速览

core/与客户无关的共享核心（解析、年月识别、核对服务层）
clients/client_a/客户A的读取/核对规则/罚款/写出 + 配置 config.py（节假日、补班日）
web/Web 版：server.py(后端) + static/index.html(前端)
app/桌面版界面；releases/ 里是打包好的 exe

④ 怎么跑起来

本机/服务器跑 Web 版（Python 一律用 uv）：

cd 项目目录
uv run python -m uvicorn web.server:app --host 0.0.0.0 --port 8000
# 浏览器访问 http://服务器IP:8000

依赖：fastapi、uvicorn、python-multipart、openpyxl、xlrd（装法见部署文档）。

⑤ 怎么更新上线（最常做）

① 在 GitHub 上改代码（或本地改完 git push）
② 服务器上：git pull            # 拉最新代码
③ 重启服务：systemd 的话 → sudo systemctl restart kaoqin
            （或重新 docker build / docker run）
④ 用户刷新页面即新版
💡 改业务规则最常改 clients/client_a/config.py（每月节假日/补班日）和 clients/client_a/ 下的核对/罚款逻辑。

⑧ 出问题怎么查

  • 页面打不开 → 先看服务在不在跑（systemctl status）、端口/防火墙有没有放行。
  • 核对结果不对 → 看「运行日志」、对一下 config.py 当月节假日是否配对。
  • 报错 → 看服务器日志，倒着看最后一行（错误类型 + 文件:行号）。
