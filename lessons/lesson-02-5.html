2.5　函数、模块、import

本课目标：把一段动作"打包复用"，并学会"借用"别的文件里的功能。

① 函数 = 打包好的一段动作

把常做的事打包，起个名字，以后一句话就能反复用。def 定义，括号里是"要给它的料"，return 是"产出"。

def add(a, b):      # 定义一个叫 add 的函数
    return a + b
print(add(3, 5))    # 调用它 → 8
🔑 函数 = 起了名字、可反复用的一段动作。

② 模块 与 import

  • 模块 = 一个 .py 文件（一盒工具）。
  • import = "借用"另一个文件里的功能。from A import b = 从 A 这盒工具里借 b。

③ 在我们项目里

def run_reconcile(...) —— 把"整套核对流程"打包成一个函数，桌面版和 Web 版都调用它。
from core.service import run_reconcile —— Web 后端"借用"核对核心。
项目拆成 core/clients 等多个模块，就是把工具分门别类装盒，用谁 import 谁。

④ 小结

def 定义函数return 产出模块=一个.py文件import=借工具
🧠 记忆点：函数=可复用的动作；import=从别的盒子借工具
