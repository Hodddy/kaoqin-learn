5.1　HTML / CSS / JS：网页的"骨、皮、魂"

本课目标：分清网页三件套各自负责什么。

① 三件套，一个比喻：盖房子

🦴
HTML
骨架·结构
+
🎨
CSS
装修·样式
+
⚡
JavaScript
机关·行为
🔑 HTML 搭骨架（有什么），CSS 管样子（长啥样），JS 管行为（点了会怎样）。

② 各管什么

三件套负责例子
HTML页面有哪些东西一个按钮、一个表格、一个上传框
CSS这些东西长什么样按钮是蓝色圆角、表格隔行变色
JS用户操作后干什么点按钮→发请求→把结果画出来

③ 在我们项目里

web/static/index.html 一个文件里就有这三样：
<body> 里是 HTML（卡片、按钮、表格）；<style> 里是 CSS（蓝色主题、10 套皮肤）；<script> 里是 JS（点"开始核对"发请求、画结果）。

④ 小结

HTML=结构(骨)CSS=样式(皮)JS=行为(魂)
🧠 记忆点：骨架(HTML)+装修(CSS)+机关(JS) = 一个网页
