4.4　返回 JSON、文件下载、状态码与报错

本课目标：后端怎么把"结果数据"和"可下载文件"回给浏览器。

① 返回结果数据 → JSON

直接 return 一个字典，FastAPI 自动变 JSON。我们返回的是：总人数、OK/异常数、每个人的结果、运行日志。

return {"ok_total":36, "err_total":3, "months":[...], "logs":[...]}

② 返回文件 → 让浏览器下载

处理后的 Excel 用 FileResponse(路径) 回给浏览器，浏览器就弹出下载。我们用一个"令牌(token)"对应一个文件，前端拿令牌去 GET /api/download/{token} 下载。

③ 出错 → 用状态码告诉前端

客户文件不是 .xls？raise HTTPException(400, "客户文件必须为 .xls") —— 回一个 400（你错了）+ 说明。前端看到非 200 就提示用户。
（还记得模块 1 的状态码吗？4xx 怪客户端、5xx 怪服务器，这里就用上了。）

★ 补充：JSON 是什么

JSON（念"杰森"）= 程序之间传数据的"通用填表格式"，人也能看懂。我们核对完，结果就打包成 JSON 发回浏览器：

{
  "ok_total": 36,
  "err_total": 3,
  "months": [
    { "month": "2026-05", "ok": 36, "err": 3 }
  ]
}
  • { } 对象：装一组"名字: 值"，如 "ok_total": 36。
  • [ ] 列表：装"一排东西"，如 months 里每个月一项。
  • 值可以是：数字、文字(带引号)、真假(true/false)，还能再套 {}/[]。
🔑 JSON 几乎就是"文字版的 Python 字典 + 列表"（{}≈字典、[]≈列表，见 2.3 课）。所以后端 return 一个字典，FastAPI 自动转成 JSON——浏览器收到再画成表格。HTTP 响应的 body 装的就是它。

④ 小结

return字典→JSONJSON={}名值/[]一排FileResponse 给下载HTTPException 报错+状态码
🧠 记忆点：数据回 JSON（文字版字典+列表），文件回 FileResponse，错误回状态码
