🗣️ 跟 IT 对话 · 名词速查

开会前扫一眼，这些词都能对答如流。每个都配"一句话人话 + 例子"。

⭐ 最容易懵的：IP 与 端口（总机 + 分机）

IP = 公司总机号码　找到"哪台电脑"。如 192.168.1.20
端口 = 分机号　找到"机器里哪个程序"。我们的考勤服务=8000
所以 192.168.1.20:8000 = 打这台机器的总机，转 8000 分机（考勤服务）。一台机器多个程序，靠不同端口区分（网站80/443、数据库3306、远程登录22、我们8000）。
服务器 Server
一台一直开机、专门给别人提供服务的电脑（多为 Linux，常是切出来的虚拟机）。
例：IT 给你"一台 Linux 虚拟机"。
IP 地址
电脑在网络里的"门牌号/总机号"。
例：192.168.1.20、本机 127.0.0.1。
端口 Port
机器里"哪个程序"的分机号。
例：考勤服务在 8000。
域名 / 内网域名
给 IP 起的好记名字；内网域名只在公司网内有效。
例：kaoqin.公司.com，省得记 IP。
DNS
"名字→IP"的查号台。输域名，它查出 IP 再连。
问 IT："帮我把域名 DNS 指向这台服务器。"
网段
一批连号的 IP（一群机器）。
例：HR 网段 10.20.30.0/24（IT 会给你具体值）。
内网 / 公网
内网=公司内部网络（只内部人能连）；公网=整个互联网。
内部系统一般"只放内网"更安全。
防火墙 / 白名单
门卫。防火墙默认关端口，要"放行 8000"；白名单=只许某些 IP 进。
"请放行 8000，限 HR 网段。"
VPN
从公司外"拉根线进内网"，连上后就像坐在公司里。
"外勤同事走 VPN 访问。"
HTTPS / 证书
加密的网址（🔒）。靠"证书"建加密通道。
"申请一张证书，全程走 HTTPS。"
Nginx 反向代理
程序前面的"前台"：用户先到它，它转给后面的服务，并负责 HTTPS。
用户访问 443 → Nginx → 转 8000。
systemd
Linux 的"服务管家"：让程序常驻、开机自启、崩了自动重启。
告别"黑窗口一关就停"。
Docker 镜像 / 容器
镜像=打包好的"模具"(程序+环境)；容器=用模具跑起来的"实例"。
交给 IT 一个镜像，他们 docker run 即起。
SSO 单点登录
公司一次登录、所有系统通用，不用各系统单独注册。
"能否接公司统一登录(SSO)，复用员工账号？"
