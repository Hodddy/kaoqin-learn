5.4　样式与主题（我们做的 10 套皮肤）

本课目标：理解 CSS 怎么控制样子，"换肤"是怎么做到的。

① CSS 怎么写

CSS 是"给某类元素定样子"：选择器 { 属性: 值; }。

.btn { background: #4f46e5; color: white; border-radius: 8px; }
# 凡是 class="btn" 的元素，都蓝底白字圆角

② "换肤"的秘密：CSS 变量

把主色定义成一个变量 --accent，全页都用它。换肤时只改这一个变量的值，整页颜色跟着变——这就是我们 10 套主题的原理。

:root { --accent: #4f46e5; }     # 定义主色变量
.btn { background: var(--accent); } # 处处引用它
🔑 颜色不写死，存进变量；换肤=换变量的值，一改全变。

③ 在我们项目里

右上角"主题"下拉的 10 套浅色皮肤，就是准备了 10 组颜色，选哪套就把 --accent 等变量换成那套的值，并存进浏览器记住你的选择。

④ 小结

CSS=选择器{属性:值}CSS变量存主色换肤=换变量值
🧠 记忆点：样式靠 CSS，换肤靠改一个颜色变量
