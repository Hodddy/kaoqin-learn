8.2　依赖、配置、密钥管理

本课目标：让项目"在别人机器/服务器上也能装起来、好维护、不泄密"。

① 依赖：把"用了哪些库"写下来

项目用了 fastapi、openpyxl、xlrd 等"别人的库"，这些叫依赖。要列个清单（如 requirements.txt），别人一条命令就能装齐，不用猜。

② 配置：会变的值别写死

端口、路径、节假日这类会变的，集中放配置里（我们的客户配置在 config.py）。换环境只改配置，不改逻辑代码。

③ 密钥：绝不进代码、不进 Git

密码、token、证书这类秘密，用环境变量或专门的密钥管理来传，绝不硬写进代码、绝不提交到 GitHub（我们那个 .gitignore 就把真实数据挡在库外）。
反例提醒：你那个 GitHub PAT 在聊天里露过明文，用完一定要吊销——这就是密钥泄露的真实场景。
🔑 依赖列清单、配置别写死、密钥别外露——三件让项目"专业又安全"的事。

④ 小结

依赖→requirements清单会变的值进配置密钥走环境变量秘密绝不进Git
🧠 记忆点：清单装依赖、配置存变量、密钥永不上库
