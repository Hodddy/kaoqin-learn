4.2　写第一个接口：GET /api/clients

本课目标：看懂一个最简单的"接口"是怎么写出来的。

① 接口 = 一个"窗口" + 一段处理

接口就是"某个地址收到请求时，跑哪段代码、回什么"。FastAPI 用 装饰器 @app.get(...) 把"地址"和"函数"绑起来。

@app.get("/api/clients")     # 谁来 GET 这个地址
def api_clients():           # 就跑这个函数
    return [{"key":"client_a","display":"客户A"}]  # 回这个
🔑 @app.get("/地址") 上面贴着，下面的函数就负责回应这个地址的 GET 请求。

② return 的东西会自动变 JSON

你 return 一个列表/字典，FastAPI 自动转成 JSON 发回浏览器。浏览器前端再拿这个数据填下拉框。

③ 在我们项目里

GET /api/clients 就是这么写的，返回客户列表，驱动界面里"客户"下拉框。
前端用 fetch('/api/clients') 来调它（前端怎么调是模块 5）。

④ 小结

@app.get 绑地址函数负责回应return 自动变 JSON
🧠 记忆点：装饰器绑地址，函数写回应，return 即响应
