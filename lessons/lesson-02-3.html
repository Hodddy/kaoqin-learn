2.3　列表 与 字典（项目里到处都是）

本课目标：会用两种最常用的"装一堆东西"的容器。

① 列表 = 一排有序的盒子

列表用 [ ]，里面按顺序放多个东西，用"第几个"取（从 0 数起）。

months = ["2026-05", "2026-06", "2026-07"]
print(months[0])   # 第 0 个 → 2026-05
print(len(months)) # 一共几个 → 3

② 字典 = 带标签的盒子

字典用 { }，每份数据有个"标签(键)"，用标签取，不靠顺序。

person = {"姓名": "张三", "出勤": 22}
print(person["姓名"])  # 用标签取 → 张三
🔑 列表按"第几个"取，字典按"叫什么"取。

③ 在我们项目里

results = {} 然后 results[姓名] = 核对结果 —— 字典：用姓名当标签存每个人的结果。
MONTHLY_COLS = {"姓名":0, "出勤":2, ...} —— 字典：列名→第几列。
rows = [...] 一行行结果 —— 列表：按顺序排。

④ 小结

列表 [ ] 有序，按位置取字典 { } 带标签，按键取len() 看有几个
🧠 记忆点：[ ]排队（看第几个）、{ }贴标签（看叫什么）
