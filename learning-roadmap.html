🎓 从零到部署 · 学习路线图

目标：从完全不懂 → 能独立写出并在大公司部署「考勤核对系统」这样的项目。全程以我们正在做的真实项目为教材。

每一课怎么上（固定套路，轻松跟）

  1. 概念：用大白话讲清这节是什么
  2. 生活比喻：先有画面感
  3. 在我们项目里长什么样：直接看真实代码 / 真实场景
  4. 动手小练习：你跟着敲几行，立刻有反馈
  5. 小结 + 一句话记忆点
🟦 地基🟩 编程/核心🟪 前端 🟥 数据库🟧 部署（你的主目标）⬛ 工程化

1计算机与网络入门 —— 打地基

先搞懂"电脑在干嘛、机器之间怎么对话"，HTTP 这次彻底讲透。
1.1程序、文件、"运行"到底是什么
1.2客户端 vs 服务器：谁请求、谁服务
1.3机器怎么互相找到：IP、端口、域名、DNS
1.4HTTP 深入：请求/响应、方法、状态码、头、body

2Python 编程基础 —— 拿起工具

从零学会写代码，每个知识点都用项目里的真实片段练。
2.1Python 是什么 + 用 uv 安装与运行
2.2变量、数字、字符串、布尔
2.3列表、字典（项目里到处都是）
2.4条件判断、循环
2.5函数、模块、import
2.6读写文件 + 操作 Excel（openpyxl/xlrd）
2.7看懂报错、调试入门

3读懂并能写"核对核心"

把项目最值钱的业务逻辑吃透，能自己改/扩展。
3.1项目分层：core/clients/app/web 为什么这么分
3.2数据模型 dataclass：把一行考勤变成对象
3.3解析公司数据（格式A/B）、年月识别
3.4核对规则与罚款逻辑
3.5插件化：怎么扩展一个新客户

4做成 Web 后端

用 FastAPI 把核心包成"网络服务"，能被浏览器调用。
4.1Web 框架是什么、为什么用 FastAPI
4.2写第一个接口：GET /api/clients
4.3接收上传文件：POST /api/reconcile
4.4返回 JSON、文件下载、状态码与报错
4.5复用核对核心：服务层 run_reconcile

5前端三件套

HTML/CSS/JS，把界面做出来、把接口连起来。
5.1HTML 结构 · CSS 样式 · JS 行为
5.2表单、文件选择、按钮
5.3用 fetch 调接口、把结果画成表格
5.4样式与主题（我们做的 10 套皮肤）

6数据库与"历史记录"

让项目能"记住东西"，实现界面预留的历史记录功能。
6.1数据库是什么、为什么需要
6.2SQL 与 SQLite 入门
6.3实战：给项目加"保存历史核对结果"

7企业级部署 —— 上服务器、对接 IT★ 你的主目标

从"自己电脑能跑"到"在大公司服务器上稳定对外服务"，并能和 IT 部门专业对接。
7.1本机 vs 服务器：到底差在哪
7.2让服务常驻：systemd / 进程守护（告别黑窗口）
7.3反向代理 Nginx + HTTPS 证书
7.4网络：内网/公网、端口、防火墙、白名单、VPN
7.5安全与鉴权：登录、token、最小权限
7.6Docker 容器化（大公司常要）
7.7与 IT 部门交涉清单：你要什么、给什么、怎么对接

8工程化与长期维护

让项目专业、可协作、能长期跑。
8.1Git / GitHub 协作（你已在用）
8.2依赖与配置、密钥管理
8.3日志、监控、备份、上线检查单
